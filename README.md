# החתונה של רבקה ומענדי

אתר התארגנות ואישורי הגעה. Cloudflare Worker + D1 (+ R2 לתמונות מהאורחים).
נפרד לגמרי מכל אתר אחר: קוד, מסד נתונים, אחסון וסיסמה משלו.

- `/app` דף ההתארגנות (רבקה, דיאמנט, מענדי, חני)
- `/r/<token>` דף אישור ההגעה של כל מוזמן
- `/vort`, `/gallery` העלאת תמונות מהאורחים והגלריה

## הגדרה חד-פעמית
1. ב-Cloudflare: Workers & Pages → Create → Import a repository → לבחור את המאגר הזה → Deploy.
   מסד הנתונים ואחסון התמונות נוצרים לבד בפריסה הראשונה, והטבלאות נוצרות לבד בכניסה הראשונה.
2. Settings → Variables and Secrets → Add → Secret בשם `FAMILY_KEY` ← סיסמת המשפחה.
3. מכאן כל שינוי שנדחף ל-main עולה לאתר לבד.
